# Third-party notices

kraken-hub itself is [MIT](LICENSE). This file covers the third-party **assets**
vendored into the repository and shipped with the built site — the things a
licence follows even though they are not code.

Third-party **npm dependencies** are not listed here: `npm run licenses`
generates `docs/third-party-licenses.md` from the production dependency tree
(generated, not committed), and that file is the record for them.

## Fonts

The six curated text faces (`src/modules/text/schema.ts` → `TEXT_FACES`) are
vendored under `public/fonts/`, one latin-subset `woff2` per face, and are
fetched only when a text layer is actually set to that face. Every one of them is
under the **SIL Open Font License, Version 1.1**. Each family's `OFL.txt` is
reproduced verbatim next to its font file, with the copyright line exactly as
upstream gives it.

| id          | family           | copyright                                                                                                                                           | licence                          |
| ----------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| `display`   | Anton            | `Copyright 2020 The Anton Project Authors (https://github.com/googlefonts/AntonFont.git)`                                                           | `public/fonts/display/OFL.txt`   |
| `serif`     | Playfair Display | `Copyright 2017 The Playfair Display Project Authors (https://github.com/clauseggers/Playfair-Display), with Reserved Font Name "Playfair Display"` | `public/fonts/serif/OFL.txt`     |
| `mono`      | JetBrains Mono   | `Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono)`                                                    | `public/fonts/mono/OFL.txt`      |
| `rounded`   | Quicksand        | `Copyright 2011 The Quicksand Project Authors (https://github.com/andrew-paglinawan/QuicksandFamily), with Reserved Font Name “Quicksand”.`         | `public/fonts/rounded/OFL.txt`   |
| `condensed` | Oswald           | `Copyright 2016 The Oswald Project Authors (https://github.com/googlefonts/OswaldFont)`                                                             | `public/fonts/condensed/OFL.txt` |
| `script`    | Pacifico         | `Copyright 2018 The Pacifico Project Authors (https://github.com/googlefonts/Pacifico)`                                                             | `public/fonts/script/OFL.txt`    |

The binaries are the `latin` unicode-range `woff2` subsets published by the
Google Fonts CSS API, taken once and committed — the display never contacts
`fonts.googleapis.com` or `fonts.gstatic.com`, which invariants 4 and 8 forbid.

| file                                    | bytes  |
| --------------------------------------- | ------ |
| `public/fonts/display-400.woff2`        | 18,612 |
| `public/fonts/serif-variable.woff2`     | 38,404 |
| `public/fonts/mono-variable.woff2`      | 31,432 |
| `public/fonts/rounded-variable.woff2`   | 28,244 |
| `public/fonts/condensed-variable.woff2` | 21,472 |
| `public/fonts/script-400.woff2`         | 32,280 |

`src/modules/text/fontAssets.test.ts` holds the 40 kB-per-face budget, checks the
`wOF2` magic bytes, and fails if a family loses its licence entry here.

## Media

`public/demo/demo.mp4` — the clip a cold display boots into — is generated by
[`scripts/make-demo.mjs`](scripts/make-demo.mjs) from synthesised shapes. It
embeds no third-party footage and carries the repository's own MIT licence.
`ffmpeg` runs that script but is a build-time tool: nothing of it is shipped.
